# Обучающая веб-платформа CodnitoWeb

Веб-приложение для обучения веб-разработке. Содержит теоретические статьи, интерактивные тесты для проверки знаний и личный кабинет пользователя.

---

## 🐧 Инструкция по локальному развертыванию на Linux

<details>
<summary>Нажмите, чтобы развернуть инструкцию для Linux</summary>

### Шаг 1. Открытие проекта и подготовка окружения
1. Откройте скачанную папку проекта (`h_quiz_v8_postgresql`) в редакторе **VS Code**.
2. Откройте встроенный **терминал VS Code** (меню *Terminal -> New Terminal* или нажмите `Ctrl + ~`).
3. В **терминале VS Code** введите команды для создания и активации изолированного окружения:

```bash
# [В ТЕРМИНАЛЕ VS CODE] Создаем виртуальное окружение
python3 -m venv .venv_linux

# [В ТЕРМИНАЛЕ VS CODE] Активируем его
source .venv_linux/bin/activate
```
*После этого в начале строки терминала появится плашка `(.venv_linux)`.*

### Шаг 2. Установка библиотек
В том же **терминале VS Code** (где активна плашка окружения) установите все необходимые для проекта библиотеки:

```bash
# [В ТЕРМИНАЛЕ VS CODE] Обновляем установщик пакетов
pip install --upgrade pip setuptools

# [В ТЕРМИНАЛЕ VS CODE] Устанавливаем Django, dotenv, psycopg и др.
pip install -r requirements.txt
```

### Шаг 3. Настройка файла переменных `.env`
1. В **терминале VS Code** создайте личный скрытый файл настроек из шаблона:
   ```bash
   # [В ТЕРМИНАЛЕ VS CODE] Копируем шаблон в реальный файл
   cp .env.example .env
   ```
2. Сгенерируйте в **терминале VS Code** новый случайный секретный ключ:
   ```bash
   # [В ТЕРМИНАЛЕ VS CODE] Генерируем ключ безопасности
   python3 -c "import secrets; print(secrets.token_urlsafe(50))"
   ```
   *Скопируйте строку, которую выдаст терминал.*
3. В **интерфейсе VS Code** (в левой панели с файлами) найдите и откройте созданный файл **`.env`**.
4. Вставьте скопированный ключ в строку `SECRET_KEY`, а ниже укажите параметры вашей базы данных:

```env
SECRET_KEY=вставьте_сюда_скопированную_строку

DB_HOST=localhost
DB_PORT=5432
DB_NAME=h_quiz_db
DB_USER=fizzi_dev
DB_PASSWORD=ваш_надежный_пароль_для_базы
```
*Сохраните файл в VS Code (`Ctrl + S`).*

### Шаг 4. Создание базы данных в PostgreSQL
Для управления СУБД нам понадобятся права суперпользователя системы.
1. Откройте обычный **терминал Linux** (вне VS Code, например, нажав `Ctrl + Alt + T`).
2. Зайдите в консоль управления базой данных:
   ```bash
   # [В ОБЫЧНОМ ТЕРМИНАЛЕ LINUX] Входим в СУБД Postgres
   sudo -u postgres psql
   ```
   *(Система попросит пароль от вашего компьютера — введите его и нажмите Enter).*
3. Вставьте по очереди следующие SQL-команды прямо в **консоль Postgres** (строка начинается с `postgres=#`). Чтобы вставить текст, нажмите **правую кнопку мыши -> Вставить** или кликните на **колёсико мыши**:

```sql
-- [В КОНСОЛИ POSTGRES] Создаем пользователя (пароль должен совпадать с .env)
CREATE USER fizzi_dev WITH PASSWORD 'ваш_надежный_пароль_для_базы';

-- [В КОНСОЛИ POSTGRES] Создаем пустую базу данных
CREATE DATABASE h_quiz_db OWNER fizzi_dev;

-- [В КОНСОЛИ POSTGRES] Даем права пользователю
GRANT ALL PRIVILEGES ON DATABASE h_quiz_db TO fizzi_dev;

-- [В КОНСОЛИ POSTGRES] Выходим обратно в систему
\q
```
*После выполнения `\q` обычный терминал Linux можно закрыть.*

### Шаг 5. Применение миграций и загрузка контента
Вернитесь в **терминале VS Code** (где открыт ваш проект и активно окружение `(.venv_linux)`). Выполните команды для настройки таблиц и импорта статей с тестами:

```bash
# [В ТЕРМИНАЛЕ VS CODE] Переходим в папку, где лежит manage.py
cd my_website_browser1

# [В ТЕРМИНАЛЕ VS CODE] Создаем структуру таблиц в базе данных
python manage.py migrate

# [В ТЕРМИНАЛЕ VS CODE] Загружаем готовые учебные тесты и статьи из файла
python manage.py loaddata content_fixtures.json
```

### Шаг 6. Запуск сервера
Запустите локальный сервер разработки в **терминале VS Code**:

```bash
# [В ТЕРМИНАЛЕ VS CODE] Запускаем сайт
python manage.py runserver
```

Откройте любой браузер на компьютере и перейдите по адресу: **`http://127.0.0`**
</details>

## 🪟 Инструкция по локальному развертыванию на Windows

<details>
<summary>Нажмите, чтобы развернуть инструкцию для Windows</summary>

### Шаг 1. Открытие проекта и подготовка окружения
1. Установите **Python** версии 3.11+ (обязательно отметьте галочку *"Add Python to PATH"* при установке).
2. Откройте скачанную папку проекта (`h_quiz_v8_postgresql`) в редакторе **VS Code**.
3. Откройте встроенный **терминал VS Code** (меню *Terminal -> New Terminal*). Убедитесь, что справа в выпадающем списке терминала выбран **Command Prompt (CMD)** или **PowerShell**.
4. В **терминале VS Code** введите команды для создания и активации виртуального окружения:

```powershell
# [В ТЕРМИНАЛЕ VS CODE] Создаем виртуальное окружение
python -m venv .venv_windows

# [В ТЕРМИНАЛЕ VS CODE] Активируем его (для Command Prompt / CMD)
.venv_windows\Scripts\activate.bat

# Альтернатива: [В ТЕРМИНАЛЕ VS CODE] Если у вас активен PowerShell
.venv_windows\Scripts\Activate.ps1
```
*После активации в начале строки терминала появится зеленая плашка `(.venv_windows)`.*

### Шаг 2. Установка библиотек
В том же **терминале VS Code** (где активна плашка окружения) обновите установщик и скачайте необходимые зависимости:

```powershell
# [В ТЕРМИНАЛЕ VS CODE] Обновляем pip
python -m pip install --upgrade pip setuptools

# [В ТЕРМИНАЛЕ VS CODE] Устанавливаем библиотеки проекта
pip install -r requirements.txt
```

### Шаг 3. Настройка файла переменных `.env`
1. В **терминале VS Code** скопируйте файл-шаблон:
   ```powershell
   # [В ТЕРМИНАЛЕ VS CODE] Создаем рабочий файл настроек
   copy .env.example .env
   ```
2. Сгенерируйте в **терминале VS Code** секретный ключ:
   ```powershell
   # [В ТЕРМИНАЛЕ VS CODE] Создаем ключ шифрования
   python -c "import secrets; print(secrets.token_urlsafe(50))"
   ```
   *Выделите мышкой и скопируйте (`Ctrl + C`) строку, которую выведет терминал.*
3. В левой панели **VS Code** откройте созданный файл **`.env`** и заполните его:

```env
SECRET_KEY=вставьте_сюда_скопированную_строку

DB_HOST=localhost
DB_PORT=5432
DB_NAME=h_quiz_db
DB_USER=fizzi_dev
DB_PASSWORD=ваш_надежный_пароль_для_базы
```
*Сохраните файл в VS Code (`Ctrl + S`).*

### Шаг 4. Создание базы данных в PostgreSQL на Windows
1. Скачайте и установите **PostgreSQL для Windows** с официального сайта.
2. В меню «Пуск» найдите и запустите приложение **SQL Shell (psql)**.
3. Нажимайте `Enter` на первые четыре вопроса (Server, Database, Port, Username), чтобы оставить их по умолчанию. Когда появится запрос `Password for user postgres`, введите пароль, который вы указали при установке PostgreSQL (символы при вводе скрыты) и нажмите `Enter`.
4. В открывшееся окно консоли (строка начнется с `postgres=#`) вставьте комбинацией клавиш **`Ctrl + V`** или **правым кликом мыши** следующие команды по одной:

```sql
-- [В ОКНЕ SQL SHELL] Создаем пользователя
CREATE USER fizzi_dev WITH PASSWORD 'ваш_надежный_пароль_для_базы';

-- [В ОКНЕ SQL SHELL] Создаем базу данных
CREATE DATABASE h_quiz_db OWNER fizzi_dev;

-- [В ОКНЕ SQL SHELL] Выдаем права доступа
GRANT ALL PRIVILEGES ON DATABASE h_quiz_db TO fizzi_dev;

-- [В ОКНЕ SQL SHELL] Закрываем окно
\q
```

### Шаг 5. Применение миграций и загрузка контента
Вернитесь в **терминал VS Code**. Выполните команды для создания структуры таблиц и импорта учебных статей/тестов:

```powershell
# [В ТЕРМИНАЛЕ VS CODE] Переходим в папку с manage.py
cd my_website_browser1

# [В ТЕРМИНАЛЕ VS CODE] Создаем таблицы в PostgreSQL
python manage.py migrate

# [В ТЕРМИНАЛЕ VS CODE] Наполняем базу данных контентом
python manage.py loaddata content_fixtures.json
```

### Шаг 6. Запуск сервера
Запустите проект в **терминале VS Code**:

```powershell
# [В ТЕРМИНАЛЕ VS CODE] Запускаем локальный веб-сервер
python manage.py runserver
```

Откройте ваш браузер и перейдите по адресу: **`http://127.0.0`**
</details>

## 🛠 Технологический стек
* **Backend:** Python 3.13, Django 6.1.1
* **Database:** PostgreSQL (драйвер `psycopg 3`)
* **Environment:** python-dotenv (управление конфигурацией)
* **DevOps:** Docker (файлы конфигурации `Dockerfile` и `docker-compose.yml` в корне репозитория)
