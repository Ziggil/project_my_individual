# Roadmap проекта CodnitoWeb

План развития образовательной платформы **CodnitoWeb** — сайта обучения веб-разработке со статьями и интерактивными тестами.

---

## 🎯 Цель проекта

Разработать полноценную образовательную платформу, которая объединяет:

- **Теоретические статьи** по веб-разработке.
- **Интерактивные тесты** для проверки знаний.
- **Личный кабинет** студента с результатами.
- **Аналитику** для преподавателя.

Проект — **индивидуальный** в колледже. Цель — довести до уровня **коммерческого** продукта.

---

## 🛠 Технологический стек

**Backend:**
- Python 3.13
- Django 6.1.1
- Django REST Framework (DRF)
- SimpleJWT (JWT-авторизация)
- python-dotenv

**База данных:**
- PostgreSQL

**Frontend:**
- JavaScript (jQuery)
- Bootstrap 4.4.1
- HTML, CSS

**DevOps:**
- Docker, docker-compose

**В планах (часть архитектуры):**
- **C# (ASP.NET Core)** — высоконагруженный микросервис аналитики (большие данные, параллельно к PostgreSQL).
- **FastAPI** — асинхронный микросервис метрик.
- Nginx, Gunicorn (деплой на VPS)
- CI/CD через GitHub Actions

## 📂 Структура проекта

### Шаблоны

```
templates/
├── base_dirs/              # Папка для общих шаблонов (каркасов)
│   ├── base.html           # Общий шаблон для АВТОРИЗОВАННЫХ страниц (с навигацией)
│   └── base2.html          # Общий шаблон для НЕАВТОРИЗОВАННЫХ страниц (логин, регистрация)
├── main/
│   ├── index.html          # Главная страница (лендинг) — наследует base_dirs/base2.html
│   ├── about.html          # Страница «Про нас» — наследует base_dirs/base2.html
│   ├── home.html           # Профиль (данные пользователя, тесты, статьи) — наследует base_dirs/base.html
│   └── links.html          # Полезные ссылки — наследует base_dirs/base.html
├── users/
│   ├── register.html       # Регистрация — наследует base_dirs/base2.html
│   ├── login.html          # Вход — наследует base_dirs/base2.html
│   └── logout.html         # Выход — наследует base_dirs/base2.html
├── articles/               # Страницы статей — наследуют base_dirs/base.html
└── quizes/                 # Страницы тестов — наследуют base_dirs/base.html              
```

**Принцип:** все дочерние шаблоны наследуются от `base.html` или `base2.html` через `{% extends 'base.html' %}`  или `{% extends 'base2.html' %}`. Общий CSS — `base.css`и `base2.css` .

## 📝 О проекте

Проект создан как индивидуальный в колледже. Развивается как пет-проект для портфолио и практики. Планируется публичный деплой на сервер.

В перспективе — возможен переход в коммерческий формат: платные курсы, расширенная аналитика, интеграции для учебных заведений.
