# Roadmap проекта CodnitoWeb

План развития образовательной платформы **CodnitoWeb** — сайта обучения веб-разработке со статьями и интерактивными тестами.

---

## 🎯 Цель проекта

Разработать полноценную образовательную платформу, которая объединяет:

- **Теоретические статьи** по веб-разработке.
- **Интерактивные тесты** для проверки знаний.
- **Личный кабинет** студента с результатами.
- **Аналитику** для преподавателя.

Проект — **индивидуальный** в колледже. Цель — довести до уровня **коммерческого** продукта.

---

## 🛠 Технологический стек

**Backend:**
- Python 3.13
- Django 6.1.1
- Django REST Framework (DRF)
- SimpleJWT (JWT-авторизация)
- python-dotenv

**База данных:**
- PostgreSQL

**Frontend:**
- JavaScript (jQuery)
- Bootstrap 4.4.1
- HTML, CSS

**DevOps (в планах):**
- Docker, docker-compose
- Nginx, Gunicorn
- CI/CD через GitHub Actions

## 📍 Текущий статус

**Версия:** `v8.6.0`

**Что работает:**
- ✅ Переезд с SQLite на PostgreSQL
- ✅ Гибридная авторизация (сессии + JWT)
- ✅ REST API на DRF: список тестов, вопросы, результаты
- ✅ Дедупликация результатов через `annotate(Max('id'))`
- ✅ Сохранение ответов через DRF `@action save`
- ✅ Вёрстка всех страниц — стабильная
- ✅ Регистрация через AJAX (без перезагрузки)
- ✅ Логин через AJAX (без перезагрузки, JWT в `localStorage`)
- ✅ Refresh токена в `auth.js` (автообновление `access`)
- ✅ Вывод ошибок валидации под формой (`non_field_errors`)
- ✅ Русский язык ошибок валидации
- ✅ Общий шаблон `base2.html` для всех страниц
- ✅ Универсальный CSS `base2.css` для всех страниц
- ✅ Все шаблоны в общей папке `templates/` с подпапками
- ✅ Фронтенд: правки вёрстки, убрана личная почта из футера

**В работе:**
- 🚧 Наполнение сайта: больше статей и тестов
- 🚧 Мелкие правки фронтенда

## 📂 Структура проекта

### Шаблоны

```
templates/
├── base2.html              # Общий шаблон для всех страниц
├── main/
│   ├── index.html          # Главная страница
│   └── about.html          # Страница «Про нас»
├── users/
│   ├── register.html       # Регистрация
│   ├── login.html          # Вход
│   └── logout.html         # Выход
├── news/                   # Страницы новостей/статей
└── quizes/                 # Страницы тестов
```

**Принцип:** все дочерние шаблоны наследуются от `base2.html` через `{% extends 'base2.html' %}`. Общий CSS — `base2.css`.

## 📝 О проекте

Проект создан как индивидуальный в колледже. Развивается как пет-проект для портфолио и практики. Планируется публичный деплой на сервер.

В перспективе — возможен переход в коммерческий формат: платные курсы, расширенная аналитика, интеграции для учебных заведений.
